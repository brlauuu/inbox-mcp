inbox-mcp

A tiny MCP server that files every GitHub issue you dictate into one inbox repo, however badly the speech-to-text mangled your project names.

Why

GitHub's official MCP server can reach every repository you own. That's a problem when your repos have odd names and a transcription model has to guess them, especially if English isn't your first language. inbox-mcp exposes a single tool, create_issue, that always writes to one repository you configured. The model never picks the repo. You triage the inbox and transfer issues to the right repo later.

Features

  • MCP over Streamable HTTP (plain JSON-RPC, no SSE)
  • One tool: create_issue(title, body?)
  • Target repo is fixed server-side through GITHUB_REPO
  • Bearer-token protected
  • No dependencies, no build step. Runs on Cloudflare Workers or Vercel.

Configuration

GITHUB_REPOWhere issues go, as owner/repo.
GITHUB_PATFine-grained token for that repo only, with Issues: Read and write.
PROXY_TOKENRandom secret your MCP client sends as Authorization: Bearer ….

Want your issues private? Make the inbox repo private. This code can stay public.

Deploy to Cloudflare

npx wrangler secret put GITHUB_PAT
npx wrangler secret put PROXY_TOKEN
npx wrangler secret put GITHUB_REPO
npx wrangler deploy

Vercel deployment, Pebble setup and curl tests are in the README.
